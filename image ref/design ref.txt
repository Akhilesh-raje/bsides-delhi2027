**Physical appearance:**

- Approximately 42 metres tall.
- Monumental sandstone triumphal arch.
- Broad rectangular pillars.
- Large central arch opening.
- Detailed cornices and mouldings.
- Carved stone inscriptions.
- Decorative upper structure.
- Low raised stone base.

India Gate was designed by Edwin Lutyens, with its foundation stone laid in 1921 and dedication in 1931.&#x20;

[image](https://www.google.com/s2/favicons?domain=https://dmnewdelhi.delhi.gov.in\&sz=32)

India+1



**3D modeling instructions:**

Do not create it as a simple rectangular arch.

Model:

1. Main left and right vertical pillars.
2. Central arched opening with accurate curvature.
3. Upper horizontal entablature.
4. Projecting cornices.
5. Recessed decorative panels.
6. Stone texture variations.
7. Upper parapet and crown.
8. Inscription details.
9. Base platform and surrounding steps.

Material recommendation: warm beige and muted reddish sandstone, with subtle roughness, weathering, realistic bevels and carefully baked ambient occlusion.

**Cyberpunk transformation:**

Keep the architecture realistic. Add a controlled red light strip around selected architectural edges, very subtle holographic scanning rings and small digital markers.

The monument itself should not look like it was constructed from neon tubes.

## **9. Performance and technical requirements**

Because this is a real-time 3D website, the Metro scene should be designed around performance from the beginning.

| Component           | Recommended approach              |
| ------------------- | --------------------------------- |
| Train               | Modular GLB                       |
| Station             | Separate environment GLB          |
| Tunnel              | Repeating modular sections        |
| Escalator           | Procedural looping animation      |
| Passengers          | Instanced low-poly characters     |
| Lighting            | Baked illumination where possible |
| Reflections         | Selective reflection effects      |
| Particles           | GPU-friendly particle system      |
| Metro route         | SVG or lightweight 3D curves      |
| Interactive objects | Separate collision/hotspot meshes |

### **Three rendering profiles**

- **Ultra:** Full station detail, train reflections, atmospheric lighting and advanced post-processing.
- **Balanced:** Reduced particles, optimized train geometry and selective reflections.
- **Lite:** Simplified station, reduced lighting effects and static tunnel fallback.

For mobile, don't load the complete concourse, train interior and tunnel simultaneously. Load each environment only when the visitor approaches that chapter.

### **How to create the circular architecture in Blender**

1. Build one straight modular facade section.
2. Create repeated architectural bays.
3. Add a curve representing the circular block.
4. Duplicate the modules along the curve.
5. Rotate them to follow the circular layout.
6. Adjust the end modules to meet adjacent radial streets.
7. Create separate modules for corners and building gaps.
8. Repeat the process for the other commercial rings.

**Important:** Don't simply bend a single straight building mesh into a circle. That can distort the columns, windows and arches. Use modular segments following the circular footprint.

## **9. Performance and web implementation**

Your CP scene will be relatively large, so I recommend separating the environment into loadable chunks.

| Environment          | Loading strategy        |
| -------------------- | ----------------------- |
| Central Park         | Load first              |
| Inner Circle         | Load with main reveal   |
| Colonnade details    | Load progressively      |
| Outer Circle         | Load on camera approach |
| Underground Metro    | Reuse Metro assets      |
| Palika Bazaar        | Load on discovery       |
| Distant architecture | Low-detail assets       |
| Network effects      | Load during transition  |

**Technical recommendations:**

- Blender to GLB/GLTF.
- Draco compression for geometry.
- KTX2 for textures.
- Instanced meshes for columns, trees and streetlights.
- Baked lighting for repeated buildings.
- LOD for distant buildings.
- Reuse the existing Metro environment rather than creating another version of it.
- Separate 3D interaction hotspots from visual geometry.
- Maintain static alternatives for mobile and reduced-motion users.

The most important performance optimization is to avoid rendering every building interior and underground corridor simultaneously.
